# Estrutura de Imagens do Projeto

Esta pasta armazena todos os recursos visuais do sistema:

```
assets/img/
├── pokemon/        # Sprites e fotos dos Pokémon (ex: pikachu.png, charmander.png)
├── itens/          # Ícones de itens da loja (ex: potion.png, super-potion.png, pokeball.png)
├── treinadores/    # Fotos dos avatares de usuários (ex: ash.png, misty.png, brock.png)
├── cenarios/       # Fundos de tela para arena de batalha, centro pokémon, loja
└── icons/          # Ícones da interface (logo, ícones de tipos fogo/água/planta, moedas)
```

### Exemplo de uso no HTML/PHP:
```html
<!-- Exibir sprite de um Pokémon -->
<img src="assets/img/pokemon/pikachu.png" alt="Pikachu">

<!-- Exibir ícone de um item da loja -->
<img src="assets/img/itens/potion.png" alt="Potion">
```
